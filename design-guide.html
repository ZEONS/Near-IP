2. 타이포그래피 및 글자 굵기 (Weight Guide)

공식 글자 굵기 계층 규격 (Font Weight Standard)

권장 굵기 Tailwind Class 적용 대상 및 UI 요소 실제 렌더링 예시
700 (권장 굵기) font-bold 페이지 제목 (H1), 중요 영역 제목 (H2, H3), 모달 제목 비즈니스의 지도를 바꾸다
700 font-bold 핵심 실행 버튼 (CTA), 선택된 탭 (Active Tab) API 무료 체험
600 font-semibold 상태 배지, 보조 버튼, 비선택 탭, 입력 라벨 (`label`), 중간 강조 MATCH_SUCCESS
500 font-medium 설명, 출처, 서브 카피, 본문 보조 정보, 메트릭 라벨 5ms 초고속 API로 제공하는 솔루션
400 font-normal 일반 설명, 카드 본문 문단 (장식 목적의 과도한 굵기 지양) 수시로 변하는 유동 IP라도 정밀 추정합니다.
