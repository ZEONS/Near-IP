# 🌐 ZEONS IP 위치정보 서비스 (Near-IP)

> **"IP 주소 하나로 비즈니스의 지도를 바꾸다"**  
> 주식회사 제온스(ZEONS, Inc.)의 초정밀 B2B 위치 지능 솔루션 랜딩페이지 및 시뮬레이터 프로젝트입니다.

---

## 🚀 프로젝트 개요

**ZEONS IP 위치정보 서비스**는 인터넷 접속 IP를 실시간 분석하여 접속자의 정교한 위치를 파악하고, 통신 3사(KT, SKB, LGU+)의 공식 제휴 백본망 데이터 및 독자 위치 지능 엔진을 기반으로 5ms 이내의 초고속 위치 지능 API를 제공하는 엔터프라이즈 솔루션입니다.

---

## ✨ 주요 특징 및 핵심 기술

- **Supanova 디자인 시스템**: 딥 네이비(`bg-[#040711]`) 테마, 사이버네틱 시안 네온 하이라이트, 고품질 글래스모피즘(Glassmorphism), Pretendard 웹폰트, Iconify Solar 아이콘
- **실시간 IP 위치 탐지 시뮬레이터**: 3D 레이더 스캔 분석 모션 및 통신 3사 퀵 테스트 대시보드
- **핵심 독자 기술 탑재**:
  - **가상 전봇대 매핑 기술 (V-Pole™)** : 지능형 노드 클러스터링을 통한 유동 IP 정밀 위치 추정
  - **실시간 타겟 마케팅 광고 엔진** : 위치 기반 초고속 동적 배너 노출 알고리즘
- **데이터 신뢰도 지표**: 시·도(92%), 시·군·구(78%), 국가 단위(99.9%) 원형 SVG 게이지 차트
- **개발자 API 인터랙티브 콘솔**: 텍스트 방식 / 코드 방식 / JSON REST API 탭 전환 및 원클릭 복사
- **완벽한 법률 안전성**: PII 미수집, 위치정보보호법 준수, **통신사실확인자료 비해당** 보증
- **단독 실행(Zero-Dependency)**: 프레임워크나 백엔드 없이 브라우저에서 즉시 실행되는 `index.html` 단일 소스
